# Multithreaded Calculation Simulator

Консольное приложение для имитации многопоточного расчёта с прогресс-барами.

## 🚀 Возможности

- Настройка количества потоков
- Настройка длины расчёта
- Визуализация прогресса для каждого потока
- Вывод статистики по каждому потоку
- Подсчёт общего времени выполнения

## 🛠 Технологии

- Java 25
- Maven 3.9.6+

## 📦 Запуск

```bash
cd multithread-calc
mvn compile exec:java
```

## 📋 Вывод программы

Для каждого потока выводится:
- Номер потока по порядку
- Идентификатор потока
- Прогресс-бар выполнения
- Время выполнения после завершения

## ⚙️ Настройка

Измените константы в `Main.java`:

```java
private static final int THREAD_COUNT = 4;        // Количество потоков
private static final int CALCULATION_LENGTH = 50; // Длина расчёта
```
